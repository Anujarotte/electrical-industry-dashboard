# ⚡ Electrical Industry Comparative Dashboard

## 📊 Overview

This project presents an **interactive dashboard** for analyzing and comparing the performance of leading electrical companies such as **ABB, Siemens, Schneider Electric, Havells, and Crompton**.

The dashboard provides insights into:

* Revenue trends
* Growth analysis
* Sector-wise distribution
* Upcoming project pipeline

---

## 🎯 Objective

To build a **data-driven decision support system** that helps analyze:

* Company performance over time
* Sector contribution
* Future project opportunities

---

## 🧩 Project Architecture

```text
Data (Excel/CSV)
      ↓
Data Processing (Python / Power BI)
      ↓
Visualization (Power BI Dashboard)
```

* Project_Value_cr

## 📊 Dashboard Features

✔ KPI Cards (Total Revenue, Growth, Companies)
✔ Monthly Revenue Trend
✔ Company Comparison
✔ Sector Analysis (Treemap / Bar Chart)
✔ Project Pipeline Analysis
✔ Interactive Filters (Company, Sector, Month)
